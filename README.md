# 놀러가자 (OutingFinder)

친구랑 놀러 갈 **경기도** 장소를 찾아 주는 Windows 데스크톱 앱이에요(안드로이드 폰 앱도 있어요). 개인이 만든 무료 앱이에요.

- **테마별 둘러보기**: 맛집, 카페, 친구랑 놀거리(방탈출·보드게임·볼링), 비 와도 OK, 자연·공원, 역사·문화, 야경, 테마파크, 쇼핑, 지금 계절에 가기 좋은 곳.
  출발지 근처를 인터넷에서 찾아 사진과 함께 보여 줘요
- **검색**: "가평 카페", "파주 맛집"처럼 찾으면 네이버·카카오·한국관광공사에서 실제 장소를 모아 보여 줘요
- **장소 자세히**: 사진, 방문자 후기 AI 요약(네이버 블로그 후기의 좋은 점·아쉬운 점), 블로그 후기, 관광공사 소개·이용 시간, 작은 지도
- **찾는 범위**: 출발 시·군 / 30km 안 / 60km 안 / 경기 전체, **지도로 보기**(핀으로 위치 표시)
- **체인점 묶기**: 같은 가게 여러 지점은 카드 하나로, 가까운 지점부터 골라 보기
- **AI 코스**: 인원·이동 수단·예산·분위기를 고르면 Claude AI가 실제 가게를 검색하면서 하루 코스를 짜 줘요
- **뽑기**: 못 정하겠으면 한 곳 뽑기
- **축제**: 진행 중이거나 곧 열리는 경기도 축제 (관광공사 키가 있을 때)
- **찜**: 마음에 든 곳을 모아 두고 친구에게 보낼 글로 한 번에 복사

## 받기

**[최신 버전 내려받기 (OutingFinder.exe)](https://github.com/Leopard7711/OutingFinder-releases/releases/latest/download/OutingFinder.exe)**

- Windows 10/11 (64비트). 설치 없이 exe 하나로 실행돼요.
- 새 버전이 나오면 앱 위쪽에 알림이 뜨고, **업데이트**를 누르면 알아서 바꿔 켜져요.
- **이 페이지(github.com/Leopard7711/OutingFinder-releases)에서만 받으세요.** 다른 곳에 올라온 파일은 변조됐을 수 있어요.

### 안드로이드 폰 앱

**[폰 앱 내려받기 (OutingFinder.apk)](https://github.com/Leopard7711/OutingFinder-releases/releases/latest/download/OutingFinder.apk)** — 폰에서 이 링크를 열어 설치하세요.

- 플레이스토어 앱이 아니라서 처음에 "출처를 알 수 없는 앱 설치"를 허용해야 해요.
- Play 프로텍트가 "앱 검사"를 하라고 하면 **검사**를 누르거나 **무시하고 설치**를 누르면 돼요 (스토어 밖 앱마다 뜨는 창이라 앱에서 막을 수는 없어요).
- 새 버전이 나오면 앱 위쪽에 알림이 뜨고, **업데이트** → 설치 화면에서 **업데이트**를 누르면 돼요.
- 키는 PC와 따로 저장돼요. 폰 앱의 ⚙️ 설정에서 다시 넣어 주세요.

### "Windows의 PC 보호" 창이 뜨면

코드 서명 인증서가 없는 개인 앱이라 처음 실행할 때 Windows가 경고를 띄워요.
**추가 정보** → **실행**을 누르면 됩니다.

## 키 넣기 (⚙️ 설정)

키 없이도 미리 넣어 둔 경기도 장소 58곳은 볼 수 있어요. 아래 키를 넣으면 기능이 늘어나요. 키는 이 PC(폰은 그 폰)에만 저장돼요.

| 키 | 하면 생기는 것 | 받는 곳 | 비용 |
|---|---|---|---|
| 네이버 (Client ID·Secret) | 인터넷 장소·테마 줄, 사진, 블로그 후기 | 네이버 클라우드 콘솔 → NAVER API HUB → Application 등록 (지역·이미지·블로그) | 지금은 무료 (하루 25,000회) |
| 카카오 (REST API 키) | 인터넷 장소 더 많이 | developers.kakao.com → 내 애플리케이션 → 카카오맵 ON → REST API 키 | 무료 한도 안에서 무료 |
| 한국관광공사 (인증키) | 관광지 소개·이용 시간, 축제 | data.go.kr → 한국관광공사 국문 관광정보 서비스 활용신청 | 무료 |
| Anthropic (`sk-ant-…`) | AI 코스, 방문자 후기 요약 | console.anthropic.com → API Keys | 본인 계정에서 직접 결제, 코스 한 번에 약 50~150원 |

## 알아 두기

- 장소 정보·사진은 인터넷 검색 결과라 틀리거나 바뀌었을 수 있어요. **운영 시간·요금은 가기 전에 지도 앱에서 꼭 확인**하세요.
- 앱은 사용자 정보를 개발자에게 보내지 않아요. 검색어는 위 서비스(네이버·카카오·관광공사·Anthropic)로만 가요.
